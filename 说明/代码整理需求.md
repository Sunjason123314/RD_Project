# 代码整理需求（Code Cleanup Requirements）

> 记录时间：2026-07-17
> 项目：blade_measurement_v3.3.4（叶片测量 QT/C++ 桌面应用）

## 一、用户提出的四项要求

### 需求 1：给代码分区（尤其是 mainwindow）
- `mainwindow.cpp` 当前约 **11027 行 / 416 KB**，`mainwindow.h` 约 719 行，代码过于集中。
- 目标：对代码进行**分区/分块**，按功能划分清晰的区段（section），提高可读性和可维护性。
- 重点对象：`mainwindow.cpp` / `mainwindow.h`。

### 需求 2：删除冗余的、重复的代码
- 清理项目里重复、冗余、无实际作用的代码。

### 需求 3：把相同功能的代码放到一起（合并同类功能）
- 将功能相似/相同的函数合并统一，避免"多个函数实现差不多的功能"。
- 示例：**拟合球（fitSphere）** —— 不希望存在多个实现差不多功能的函数，应统一为一个。

### 需求 4：删除文件夹中"没有被用到"的东西
- 删除目前代码里**没有被调用**的：
  - 头文件（`.h` / `.hpp`）
  - 源文件（`.cpp` / `.cu` / `.c`）
  - 根本不涉及的**整个文件夹**

## 二、重要约束与风险提示

- **本目录未被 git 跟踪**（`git ls-files` 返回 0）。因此文件删除**无法通过 git 恢复**。
  - 执行需求 4（删除文件/文件夹）前，必须：
    1. 先列出待删清单交用户确认；
    2. 建议先做整目录备份，或将待删项移动到临时 `_trash/` 目录而非直接删除。
- `mainwindow.cpp` / `mainwindow.ui` 常被 IDE 锁定（Edit 报 EPERM），必要时改用脚本方式修改或先在 IDE 中关闭该文件。
- 分区/重构后必须能通过编译验证（Qt Creator + MSVC 2019 x64 + Ninja，Release 构建目录：`build/Desktop_Qt_5_15_2_MSVC2019_64bit-Release/`）。
- 重构应遵循"行为不变"原则：只调整结构，不改变功能逻辑，除非发现明确的 bug。

## 三、执行顺序建议

1. 先做**只读盘点**：识别未被引用的文件/文件夹、重复函数（尤其 fitSphere 类），产出清单。
2. 需求 4（删无用文件）——先出清单确认，再执行。
3. 需求 2 + 3（删冗余、合并同功能）。
4. 需求 1（mainwindow 分区）——风险最高、改动最大，放最后。
5. 每一步后编译验证。
